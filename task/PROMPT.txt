实现 escrowclock，模拟非生产档案的一次性领取。每次申请获得由不同保管人依次签发的票，签发与领取都要在岗位有效区间内。不同代理签发视其背后自然人是否相同计算；同一票批准可授权多个对象，限制领取总次数。用户取消或合规回收与领取可能并发；新政策从其批准序列起生效，不能把已经生效的回收反向取消。回执必须古今可重放，失败请求的幂等键也要持久化。
给 issue、take、audit 提供本地 CLI，写前后可注入确定崩溃，回放后任两进程竞争最后一次领取只会提交一笔。审计可以按事件时点和已知快照回答谁在何依据下领取，区分自然人重合、额度耗尽、授权过时和缺少前驱。实现小状态串行参考，用随机交错测试故障恢复等价。安全材料仅用合成 ID，存储只用本地 SQLite。
从空仓库开始，在 Windows 普通 CPU 上用 Python 3.12 标准库交付。命令输出 UTF-8 JSON，附 README、合成夹具和可直接运行的 unittest。
